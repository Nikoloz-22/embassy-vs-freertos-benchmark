# Benchmark data

`rust.csv` and `freertos.csv` each contain 1,000 measured samples with columns:

- `sample`: sample index, 0-999
- `empty`: timestamp-path overhead in CPU cycles
- `crc`: CRC-32 measurement in CPU cycles
- `roundtrip`: request/reply round-trip in CPU cycles

`raw/rust_run.txt` is the successful Rust/Embassy terminal capture used to build `rust.csv`.
`raw/freertos_raw.txt` is the target-memory dump used to build `freertos.csv`.

`summary.txt` is generated by `analysis/analyze.py`.
